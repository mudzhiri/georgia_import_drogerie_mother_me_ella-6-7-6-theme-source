# Ella Shopify Theme 7.3.1 — Source

Shopify OS 2.0 theme source for **MOTHER & ME** / Ella Multipurpose Theme (v7.3.1).

## Structure

- `assets/` — CSS, JS, images
- `blocks/` — Theme blocks
- `config/` — Theme settings
- `layout/` — Theme layouts
- `locales/` — Translations
- `sections/` — Sections
- `snippets/` — Snippets
- `templates/` — JSON templates

## Deploy

```bash
shopify theme push --store yx0wmy-qm.myshopify.com
```

Or connect this repo in Shopify Admin → Online Store → Themes → Add theme → Connect from GitHub.
